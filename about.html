About me

Student and project focus

My name is Mauricio Harp, and I’m an ICT student building this website as part of my ICT 420 coursework. This project gives me a chance to practice writing semantic HTML while also learning how structure affects accessibility, readability, and the overall organization of a website.

I’m approaching this site as more than just one class assignment. I want it to become a place where I can show the progress I make throughout the semester and keep track of the web development concepts I learn as the course moves forward.

Even though the site is still simple, working on it has already helped me understand that structure matters before design.

Project overview

Why semantic HTML matters

One of the main goals of this project is learning how semantic HTML gives meaning to different parts of a page. Using elements like header, nav, main, article, and section helps make the structure more understandable for readers, browsers, and assistive tools.

This has made me pay closer attention to how content is grouped and how headings guide someone through a page. Instead of thinking only about what looks good, I’ve been thinking more about how a page communicates its purpose and how easily someone can move through it.

As the semester continues, I want this page to reflect more of what I’m learning in ICT 420, including styling, layout, and other web development topics. That way, the site becomes a more complete record of both the course and the skills I’m building from it.
