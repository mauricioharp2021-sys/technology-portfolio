ICT 420 Project

Semantic Web Development

This portfolio is part of my work with semantic web development. One of the main goals of the project is to demonstrate how a webpage can use meaningful structure to organize information for both people and machines.

The site uses semantic HTML elements such as header, nav, main, article, section, and footer. These elements provide structure and help make the content easier to understand and navigate.

I also use CSS to create responsive layouts and improve the presentation of information. JSON-LD structured data provides additional information that can help machines understand the content and purpose of the site.

Building this portfolio has helped me strengthen my understanding of semantic HTML, accessibility, responsive design, structured metadata, and professional web development.
