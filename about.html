About me

Technology and web development interests

My name is Mauricio Harp, and I’m an ICT student at the University of Kentucky. I’m interested in technology, systems analysis, web development, and how digital tools can be used to organize and communicate information clearly.

This website highlights some of the technical skills I’ve been developing, including semantic HTML, CSS, responsive layouts, accessibility, GitHub Pages, and structured metadata using JSON-LD.

I want this site to continue growing as a portfolio where I can showcase projects, technical skills, and future work related to technology and web development.

Project overview

Why semantic structure matters

One of the main ideas behind this site is that structure matters before design. Using elements like header, nav, main, article, and section helps make pages easier to understand for users, browsers, and assistive technologies.

Building this site helped me better understand accessibility, responsive layouts, and how structured metadata can improve the way machines interpret web content.

Going forward, I plan to continue improving this portfolio by adding more technical projects, skills, and examples of my work.
