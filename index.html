Project Overview

Semantic Web Development

What this site is

Structure first

This site is being built step-by-step using semantic HTML5 structure.

This website is part of my ICT 420 course where we are learning how to structure web pages using semantic HTML. The goal of this project is to build a simple site that shows what I’m learning throughout the semester while focusing on clear structure and meaningful elements before worrying about design.

Jump to my current goal section on this page.

I use the MDN HTML documentation as a reference when I’m learning new elements and best practices.

Right now I’m mainly practicing how to organize a page with headers, sections, navigation, and other semantic elements so the content is easy to follow. That matters not only for readers, but also for screen readers and other tools that depend on good HTML structure.

Working this way has helped me understand that structure comes before design. If the page is organized well now, it will be much easier to style and expand later in the semester.

Current goal

Consistency across pages

My current goal is to keep the site organized and consistent across all three pages. I want the navigation, section structure, and overall layout to feel connected instead of looking like separate pieces.

I’m also focusing on keeping the headings in a logical order so the outline of each page makes sense. That way, as I add more content later, I can build on the structure I already have instead of starting over.

What I will add later

Content and metadata

Later in the semester I plan to expand this site by adding more content to each page, including a small portfolio section and more details about my background. I also want the site to reflect more of what I learn in class as we move into CSS, layout, and other web development topics.

I will continue improving the metadata in the head section as we learn more about search engines and structured data. Keeping the metadata clear and accurate helps both users and machines understand the purpose of the site.

For now, I’m keeping the design simple and focusing on building a strong foundation. Once the structure is solid, I can style the site more confidently without losing clarity or organization.

Tools and Workflow

VS Code, Git, and GitHub

My setup

How I’m building the site

I’m building this site using VS Code and GitHub. Writing locally and pushing updates helps me track changes and see my progress through commit history.

GitHub Pages makes it easy to publish the site as a real website. It’s helpful because I can test navigation and see how the pages work in a real browser.

My current setup is macOS. I’m keeping the workflow simple: edit, save, commit, push, and check the live site.
